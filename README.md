# ⚡ Cyber Yantra

**Hash Generator & Encoder/Decoder Toolkit** — Created by **Priyanshu Jangra**

A fully client-side web application for cryptography and encoding needs — all processing happens locally in your browser using the Web Crypto API.

## Features

### 🔐 Hash Generator
- MD5, SHA-1, SHA-256, SHA-512

### 📁 File Hash
- Drag & drop file support
- Computes MD5, SHA-1, SHA-256, SHA-512 for any file

### 🔡 Base64
- Encode text to Base64 / Decode Base64 to text

### 🔗 URL Encode/Decode
- URL-encode / URL-decode any string

### 📝 ASCII Converter
- Text → ASCII codes / ASCII codes → Text

### 💻 Binary Converter
- Text → Binary / Binary → Text

## Theme
Neon cyberpunk aesthetic with cyan (`#0ff`) and magenta (`#f0f`) accents on a dark background.

## Usage
Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox). No server or installation required.
