# 🚀 About Cyber Yantra

Cyber Yantra is a modern **Cybersecurity Utility Toolkit** designed for

- Ethical Hackers
- Cybersecurity Students
- Developers
- Security Researchers
- Bug Bounty Hunters
- CTF Players

It provides multiple encoding, decoding, hashing and conversion tools inside one clean and responsive web application.

Everything runs locally in your browser.

No server required.

No data leaves your computer.
